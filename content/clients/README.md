Client logos — one JSON file per client.

The homepage logo strip is hidden entirely while this folder is empty.

Add one file per client, e.g. clients/acme.json:

{
  "order": 1,
  "name": "Acme Pvt Ltd",
  "logo": "/static/images/clients/acme.png"
}

Only add a client whose written permission you hold to display their logo. A
logo used without permission is a legal problem, not just an awkward one.
