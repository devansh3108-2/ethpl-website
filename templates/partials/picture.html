{#- Responsive image: WebP with a PNG fallback. Parameters (set before including): img_src required /static/... path to the PNG img_alt required alt text; pass "" for decorative images img_width required intrinsic width in CSS pixels img_height required intrinsic height img_class optional class on the img_loading optional "lazy" (default) or "eager" for above-the-fold img_sizes optional sizes attribute width and height are required rather than optional on purpose: without them the browser cannot reserve space, and every image on the page shoves the layout down as it loads. That jitter is the single most irritating thing about a slow connection, and it is free to fix. The .webp path is derived by swapping the extension. That is safe because tests/test_assets.py asserts every PNG in static/images has a sibling .webp — a source that 404s is NOT retried as the fallback, so the pairing has to be guaranteed rather than assumed. -#}
